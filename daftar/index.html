Pendaftaran Program Sekolah

Mohon lengkapi data sekolah dan pilih program yang diikuti. Data Anda akan kami gunakan untuk koordinasi dan penyusunan jadwal.

1Data Sekolah

Tuliskan nama sekolah sesuai dokumen resmi.

2Penanggung Jawab (PIC)

Orang yang kami hubungi untuk koordinasi program.

3Jenjang Pendidikan

Pilih jenjang sekolah Anda. Berlaku juga untuk sekolah sederajat.

4Program yang Diikuti

Pilih satu atau lebih program sesuai kebutuhan sekolah Anda.

Pilih jenjang terlebih dahulu untuk menampilkan program.

5Pilihan Paket

Pilih paket tryout yang paling sesuai, atau tentukan jumlah sendiri. Paket tidak berlaku untuk program Evolution.

Ringkasan Pendaftaran

Periksa kembali data sebelum mengirim.
